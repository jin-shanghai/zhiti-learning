# Mac 本机安全版

这是可选的本机应用；现有单文件网页仍可独立运行。本机版要求 macOS 12 及以上，目前为待发布开发版本。

## 使用

打开「知题安全版.app」，进入「AI 设置」，点「配置或更换密钥」。服务商、模型和接口在本机窗口确认，Key 存入 Mac 系统钥匙串，不进入页面存储或学习备份。应用重启后可继续使用，系统可能要求允许钥匙串访问；长时间离开和闲置后需重新解锁。修改接口时必须重新填写对应 Key。

答错后 AI 教练会立即显示追问框。首段讲解等待期间可以先输入问题；通常几秒完成，最长约 1 分钟，并可点「取消等待」。如果接口超时、网络不可用或安全连接验证失败，页面会显示原因，修复接口后可重新生成。

学习记录保存在此应用的本机网页数据中，与 GitHub Pages 或其他浏览器分别保存。可使用「数据与设置」导出和恢复学习备份；单选、判断题库需分别保留。

## 本地构建与验证

在仓库根目录执行：

```bash
bash scripts/test-macos-security.sh
bash scripts/build-macos-app.sh
```

ZIP 产物位于 `build/macos/知题安全版.zip`，解压到下载目录后打开应用。构建脚本同时输出临时本机应用的路径，便于立即验证；在临时目录完成签名和校验，避免云同步目录自动添加 Finder 元数据使签名失效。构建使用 Swift、AppKit、WebKit 与 Security 系统框架，不安装第三方运行时。开发构建使用本机临时签名；公开分发应改用维护者的 Developer ID 签名及公证，并建立经过验证的更新流程。当前不提供 Windows/Linux 安装包。

## 权限与边界

- 原生设置窗口收集 Key；网页只看到连接状态、非秘密配置和 AI 回复。桥接没有读取 Key 的命令，仅接受内置主页面。
- Key 和接口绑定保存在一个钥匙串条目里。请求忽略网页提供的接口或模型覆盖，使用本机确认的配置。标准服务商限制到官方主机；其他接口需明确选择并确认可信地址。
- HTTPS 使用系统证书检查；重定向被拒绝，使用临时网络会话，不写日志、不保存 cookie 和响应缓存。
- 每次请求最多 25 条消息、120 KB 输入、4,096 个输出 token、2 个并发；同一应用进程最多 20 次请求/5 分钟。这些限制减少滥用，并非服务商账户硬预算；用户仍应在服务商后台设置额度。
- 手动锁定、退出或「取消等待」会取消未完成请求。离开应用一分钟或十分钟无操作也会锁定。已发出的请求仍可能由服务商计费。
- 系统钥匙串受操作系统和应用访问控制保护。恶意系统程序、受损应用构建或界面漏洞依旧可能导致滥用；不承诺绝对安全。

自动安全测试使用内存假密钥库和模拟网络，不花费真实 API 额度。另可运行 `bash scripts/test-macos-keychain.sh`，在真实系统钥匙串中创建独立的假测试条目，核对读写与删除；结束后移除该测试条目，不读取用户现有凭据。
