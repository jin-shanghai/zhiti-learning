# 知题 ZHITI

### 离线优先的刷题与学习分析工具

**导入你有权使用的题库 · 本机练习 · 查看错题与学习报告**

> 这是一个无需账号、无需服务器的静态网页。演示版本含少量原创示例题。所有答题记录和导入题库保存在当前浏览器本机。

## 30 秒开始

1. 从本仓库下载 `index.html`，用现代浏览器打开。
2. 直接开始示例练习，或打开「数据与设置」导入自己的题库。
3. 练习后查看学习报告；定期导出学习备份。

不需要安装依赖或连接网络。首次打开后可离线使用。GitHub Pages 可用于在线体验，但在线页面仍把数据保存在当前设备的浏览器中，不提供云同步。

## 功能介绍

- 单选、判断、混合练习，支持顺序或随机出题。
- 专项训练、错题强化、收藏、个人评论和练习报告。
- 导入单选、判断和多选题库；题库保存在当前浏览器。
- 学习数据可导出、导入；更换题库前会检查是否已有记录，降低题号错配风险。
- 响应式界面，适配桌面和手机浏览器。

## 导入你自己的题库

进入「数据与设置」，选择相应题型的 JSON 文件。可以使用题目数组，也可以使用 `{ "questions": [...] }` 包装格式。字段规范和示例见 [题库导入规范](docs/question-bank-format.md)。多选题模板可在应用内下载。

**请只导入你有权使用的内容。** 导入的数据只在本地浏览器处理，不会自动上传。浏览器数据可能因清理缓存、换设备或浏览器故障而丢失；请保留原始题库文件并定期导出学习备份。

## 隐私与数据

- 不含账号、云端数据库、分析脚本或外部网络请求。
- 答题、收藏、评论和导入的题库写入浏览器本地存储。
- 清除浏览器网站数据可能删除学习进度。不同设备之间不会自动同步。
- 学习备份不包含你导入的题库文件；题库文件请单独保管。
