# 使用、备份与恢复

## 使用

直接用现代浏览器打开 `index.html`。题目和练习功能在本机运行，无需联网。手机可用浏览器打开同一文件或 GitHub Pages 页面；页面会自适应屏幕。

普通练习默认开启「正确后自动下一题」：答对后约 0.45 秒进入下一题，最后一题自动生成本轮报告。答错会停留在原题，显示题库答案和解析，需要手动点「下一题」。可在练习页关闭这个开关。模拟考试始终由交卷或倒计时结束后统一评分。

## AI 设置与解题教练

「AI 设置」支持 OpenAI、DeepSeek、通义千问和其他兼容接口。选择服务商后，核对模型名称、接口地址，填写自己的 API Key，再点「测试连接」和「保存配置」。模型和地址保存在当前浏览器；密钥默认仅保存在当前页面的内存中。个人设备可主动勾选「加密保存到此浏览器」，设置至少 12 个字符的解锁密码，以后只需解锁，不必重复填写 Key。密钥和密码不会以明文保存，也不会进入学习备份。密码不会保存，忘记后只能删除并重新配置。旧版保存在标签页会话中的明文密钥会被清除，请重新配置一次。

关闭或刷新页面后自动锁定；离开页面一分钟或十分钟无操作后也会锁定并取消未完成的 AI 请求。可主动点「锁定密钥」。「删除密钥」删除当前密钥与本机加密副本，保留题目、学习记录和 AI 解析；如需撤销服务商权限，还需到服务商后台删除对应 Key。更改接口地址必须重新填写密钥，以免将原 Key 发给其他服务商。加密保存需要浏览器支持安全加密功能，不能用时仅提供临时使用。

加密保护保存在浏览器中的副本；解锁使用期间，网页仍会接触密钥。恶意扩展、网页漏洞和已被控制的电脑仍可能泄露密钥。请勿在公共设备保存。清理网站数据会删除加密副本。

## 可选的 Mac 本机安全版

Mac 安全版将密钥保存到系统钥匙串，由本机程序直接调用服务商，页面不读取完整密钥。首次通过本机设置窗口配置后，重启应用无需重新填写。更换接口需再次确认对应密钥；系统钥匙串锁定、权限变化或手动锁定时需解锁。电脑睡眠、离开应用一分钟或十分钟无操作后自动锁定。本机版和网页版的学习记录分别保存在各自环境中，可通过学习备份迁移；单选、判断导入题库需分别导出。

本机版使用本地内置界面，不让远程网页获得钥匙串调用权限；拒绝接口重定向，限制输入长度、输出数量、并发请求和短时调用频率。费用仍由用户自己的服务商账户承担，建议另在服务商后台设置额度限制。本机版目前仅支持 macOS 12 及以上，构建和安全边界见 [本机版说明](../desktop/macos/README.md)。

配置后，普通练习首次答错会请求 AI 解释题库参考答案、错误选项、知识点和记忆方法。解析按题目内容保存在本机；同题再次答错直接读取缓存。右侧教练支持继续追问和主动重新生成，这两种操作会再次调用服务商 API。题库参考答案可能有误，AI 被要求指出疑点，但生成内容仍需自行核对。AI 解析与追问可在错题、报告及题库的题目详情中离线查看，也会随学习备份保存。

浏览器会直接向你填写的服务商地址发送密钥和当前题目，不经过知题自有服务器。部分服务商会限制浏览器跨域请求，此时「测试连接」会提示无法连接，需要换用支持浏览器直连的兼容接口。请不要在公共电脑上保存密钥；浏览器扩展和第三方脚本仍可能读取页面数据，本地存储不保证绝对安全。未配置 AI 时，其余学习功能照常使用。

## 学习数据

答题历史、收藏、个人评论、AI 解析及追问和报告保存在浏览器本地存储。它们不会自动同步到另一台设备，也不会包含在仓库中。

在「数据与设置」里导出学习备份。更换设备前先保存备份；在新设备打开同版本网页后导入。请注意不同版本、不同题库的题号映射可能不同。公开版拒绝导入旧版题库备份，避免旧题号被错误套到原创演示题上。

## 题库文件

单选、判断题库可通过「数据与设置」导入 JSON；多选题库入口提供模板。单选和判断题库分别保存在本地浏览器，学习备份不包含这两类题库；请保留原始 JSON 或在「数据与设置」分别导出。多选题库保存在学习数据中，会随学习备份导出。导入任何备份前请核对题库与题号，避免旧记录对应到不同题目。

## 离线与限制

保存 `index.html` 后即可离线打开；GitHub Pages 在线体验需要首次加载网页。离线设备之间不能自动交换数据。清理浏览器数据、使用隐私窗口或更换浏览器，可能导致本地记录消失。

## 题库身份和重置保护

学习备份记录单选、判断和多选题库的内容指纹。导入学习历史前必须确保单选、判断题库与备份时一致；不含指纹的旧备份不支持直接合并，请妥善保留原始备份，在旧版环境中迁移。重置学习历史将保留已导入的多选题库。单选和判断题库仍需分别导出备份。

## 内置600道理论练习题（rc3）

此版本打开即可练习300道单选、300道判断题。单选答案和解析来自维护者提供的Excel，判断答案来自维护者提供的Markdown；判断题原文件无逐题解析。题库的知识板块依据原始题号段进行辅助整理，并非官方大纲分类。上线时改用独立存储键以防此前10道演示题的历史记录错误对应到600题；旧版本学习记录不会自动迁移，请在旧版环境中妥善保留备份。题目及答案未经逐题独立核实，不保证官方考试的权威性。
