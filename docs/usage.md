# 使用、备份与恢复

## 使用

直接用现代浏览器打开 `index.html`。题目和练习功能在本机运行，无需联网。手机可用浏览器打开同一文件或 GitHub Pages 页面；页面会自适应屏幕。

## 学习数据

答题历史、收藏、个人评论和报告保存在浏览器本地存储。它们不会自动同步到另一台设备，也不会包含在仓库中。

在「数据与设置」里导出学习备份。更换设备前先保存备份；在新设备打开同版本网页后导入。请注意不同版本、不同题库的题号映射可能不同。公开版拒绝导入旧版题库备份，避免旧题号被错误套到原创演示题上。

## 题库文件

单选、判断题库可通过「数据与设置」导入 JSON；多选题库入口提供模板。单选和判断题库分别保存在本地浏览器，学习备份不包含这两类题库；请保留原始 JSON 或在「数据与设置」分别导出。多选题库保存在学习数据中，会随学习备份导出。导入任何备份前请核对题库与题号，避免旧记录对应到不同题目。

## 离线与限制

保存 `index.html` 后即可离线打开；GitHub Pages 在线体验需要首次加载网页。离线设备之间不能自动交换数据。清理浏览器数据、使用隐私窗口或更换浏览器，可能导致本地记录消失。

## 题库身份和重置保护

学习备份记录单选、判断和多选题库的内容指纹。导入学习历史前必须确保单选、判断题库与备份时一致；不含指纹的旧备份不支持直接合并，请妥善保留原始备份，在旧版环境中迁移。重置学习历史将保留已导入的多选题库。单选和判断题库仍需分别导出备份。

## 内置600道理论练习题（rc3）

此版本打开即可练习300道单选、300道判断题。单选答案和解析来自维护者提供的Excel，判断答案来自维护者提供的Markdown；判断题原文件无逐题解析。题库的知识板块依据原始题号段进行辅助整理，并非官方大纲分类。上线时改用独立存储键以防此前10道演示题的历史记录错误对应到600题；旧版本学习记录不会自动迁移，请在旧版环境中妥善保留备份。题目及答案未经逐题独立核实，不保证官方考试的权威性。
