# 题库 JSON 格式

题库文件应使用 UTF-8 编码。可直接提供数组，也可以使用 `{ "questions": [...] }` 包装。每次最多导入 300 道单选题或判断题。导入数据只保存在当前浏览器；软件不会验证上传者是否拥有题库版权。

## 单选题

```json
{
  "questions": [
    {
      "q": "示例：学习报告的主要用途是什么？",
      "options": ["发现薄弱点", "替代学习", "自动保证考试通过", "无需复习"],
      "answer": "A",
      "category": "学习方法",
      "explanation": "报告帮助学习者发现需要复习的部分。",
      "pattern": "理解与应用",
      "step": "先判断报告能提供什么信息"
    }
  ]
}
```

必填字段：`q`（题干）、`options`（2–8个选项）、`answer`（选项字母 A–H，且对应现有选项）。`category`、`explanation`、`pattern`、`step` 可选。导入时系统按顺序生成题号 1–300。

## 判断题

```json
{
  "questions": [
    {
      "q": "示例：学习数据只保存在当前浏览器时，换设备会自动同步。",
      "answer": "错误",
      "category": "数据与设置",
      "explanation": "本地浏览器存储不会自动跨设备同步。"
    }
  ]
}
```

`answer` 支持 `正确`/`错误`、`true`/`false`、`A`/`B`。判断题选项由应用统一生成。

## 多选题

在「数据与设置」下载多选题空模板，填入题目后导入；也可以使用以下格式：

```json
{
  "questions": [
    {
      "q": "示例：哪些做法有助于保护本地学习数据？",
      "options": ["定期导出备份", "保留原始题库 JSON", "只依赖隐私窗口", "换设备前核对恢复结果"],
      "answer": ["A", "B", "D"],
      "category": "数据与设置",
      "explanation": "备份与原始题库应分别保管。"
    }
  ]
}
```

`q`、`options`（3–8 项）、`answer`（至少两个不同的有效字母）必填；`category`、`explanation` 和 `id` 可选。若自行填写 `id`，须为 `M001` 等格式且不可重复。单次最多导入 1000 道、文件不超过 2 MB。同号且内容冲突的题目会被拒绝。多选题保存在学习数据中，随学习备份导出。

## 安全和历史记录提示

- 导入前确认题库来源、授权范围和是否允许再分发；公共仓库只应放入获得明确再分发许可的内容。
- 有答题历史、收藏或评论时，应用会拒绝替换单选或判断题库，以免历史题号指向不同内容；多选题可以追加，同号冲突会被拒绝。
- 先导出学习备份，再清空历史后更换题库；学习备份不包含单选和判断题库，需自行保留原 JSON；多选题随学习备份导出。
- 不要把含个人学习笔记的备份提交到 GitHub。
