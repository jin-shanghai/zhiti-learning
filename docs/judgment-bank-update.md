## 导入规则

`scripts/import-judgment-markdown.py` 只识别 `### 数字. 题干` 格式的300道题，不会把附件开头的阅读说明、存疑表或结尾的答题技巧当成题目。每题答案只读取“答案”字段开头的“正确/错误”，存疑题答案行后的说明不会改变评分答案；解析中的补充备注会完整保留。

导入后的题目包含题号、题干、正确/错误选项、参考答案、逐题解析、原始章节、判断题标记、思考步骤和核查提醒。再次更新同格式附件时执行：

```bash
python3 scripts/import-judgment-markdown.py /path/to/人工智能训练师三级_判断题解析.md
```

脚本会在写入前检查300题、连续题号、17章和11道核查题。只校验附件而不修改网页时加 `--check-only`。

## 学习记录迁移

内置判断题版本标识为 `zhiti-ai600-judge-explained-20261013`。从旧内置判断题升级时，原判断题的答题历史、收藏、评论、练习报告、考试记录、AI讲解和未完成练习会进入本地归档，避免旧题号被套到新内容；单选题记录不受影响。用户主动导入并保存在浏览器中的自有判断题库会继续保留。

## 验证
