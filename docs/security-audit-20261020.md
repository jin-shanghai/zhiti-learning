# 2026-10-20 开源安全检查

范围：当前 main、所有公开分支和标签可达历史（114个提交、219份文件对象），v1.0.0/v1.1.0公开下载附件（20份文件）。检查常见服务商令牌、私钥、带账号密码的地址、硬编码凭据，以及学习备份、接口请求和工作流权限。

## 结果及修复

- GitHub Secret scanning、push protection 已开启，当前密钥告警为空。历史模式扫描未发现真实凭据；两处带账号地址是 Mac 安全测试的虚构输入。模式扫描不能保证发现所有格式的凭据。
- API 密钥绑定完整接口地址；更换接口必须重新输入密钥。旧版没有接口绑定的会话密钥会清除；会话保存仍为明文，个人设备加密保存功能在 PR #6 尚未合并。
- 发布和截图工作流在 PR 中仅授予读取权限；仅主分支的正式运行授予写权限，PR 检出不保存 GitHub 访问凭据。
- 修复学习备份合并后的题库版本标记，避免后续刷新错误迁移。
- 统一 NOTICE 和网页题库说明，说明当前内置600题，题库权利不自动适用 MIT。
- 扩充忽略规则，排除常见密钥文件、浏览器认证目录、日志和构建输出。

## 验证

冒烟、数据回归、导入、CI配置、真实浏览器练习与AI流程均通过。AI测试使用虚构密钥和模拟服务商，验证更换接口时不会发送保存的密钥。

## 边界

- Dependabot 告警与自动安全更新当前未启用；本次账户权限不足以读取/更改该设置。项目没有运行时第三方脚本，CI仍安装 Playwright；依赖维护需持续检查。
- PR #6 的加密密钥保存、Mac钥匙串和新版判断题解析尚未进入主分支；不应把体验版能力描述为正式版已发布。
- 未执行真实 API 调用，不读取用户设备上的真实密码或钥匙串。浏览器解锁期间的扩展、恶意脚本风险仍存在。
